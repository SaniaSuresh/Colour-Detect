Accessible Colour Detection

See colours with confidence

A modern, easy-to-use colour detection tool designed for people with colour blindness and visual impairments. Includes a read-aloud option for visually impaired people, plus camera guidance and colour feedback.

Bring the object very close to the camera for the most accurate results.

How it works

This page uses a Teachable Machine image model to identify colours captured by your webcam. Press Start, allow camera access, and the model will display the most likely colour labels.

Setup note

This page uses a hosted Teachable Machine model at https://teachablemachine.withgoogle.com/models/6kv3iqWni/. For camera access, open the page from a secure origin (HTTPS or localhost), allow permission, and tap anywhere to enable the camera.
